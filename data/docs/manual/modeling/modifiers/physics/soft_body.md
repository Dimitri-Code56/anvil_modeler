# Soft Body Modifier

The Soft Body modifier is a container for a Soft Body Physics simulation.

## Options

As the modifier is only a container its actual options are configured in the Physics Properties tab. See the Soft Body Physics Properties for more information.

## Example

The wind cone is a soft body, as the suspension.
