# Background

The Background shader node is used to add background light emission. This node should only be used for the World Output Node.

## Inputs

**Color**

Color of the emitted light.
**Strength**

Strength of the emitted light.

## Properties

This node has no properties.

## Outputs

**Background**

Standard shader output.
