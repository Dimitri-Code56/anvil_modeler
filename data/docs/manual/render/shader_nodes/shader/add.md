# Add Shader

The Add node is used to add two Shaders together.

## Inputs

**Shaders**

Standard shader inputs.

## Properties

This node has no properties.

## Outputs

**Shader**

Standard shader output.

## Example

A mix of a glossy and a diffuse shader makes a nice ceramic material.
